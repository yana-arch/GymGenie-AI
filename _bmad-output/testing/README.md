# 🧪 Testing & Quality Assurance

This directory contains all artifacts related to the quality gates and acceptance criteria of the project.

## 📋 Folder Structure

- **Test Designs**: `test-design-epic-*.md` - Detailed test plans for each functional epic.
- **ATDD Checklists**: `atdd-checklist-Story-*.md` - Acceptance Test-Driven Development checklists for individual stories.
- **System Test Design**: `test-design-system.md` - Overall system-level testing strategy.
- **Reviews**: `test-review.md` - Quality assessments and scorecards.
